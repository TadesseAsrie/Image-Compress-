# Image Compress web app

A modern, fast, and privacy-focused image compression web application built with HTML, CSS, and Vanilla JavaScript. Compress images directly in your browser without uploading them to a server.

##  Features

-  Compress JPG, JPEG, PNG, and WebP images
-  Drag & Drop image upload
-  Batch image compression
-  Adjustable compression quality
-  Optional image resizing
-  Convert between image formats
-  Before & After image preview
-  File size comparison and compression statistics
-  Download individual or all compressed images
-  Dark & Light mode
-  Fully responsive design
-  Fast browser-based processing
-  100% privacy – images never leave your device
-  Accessible and user-friendly interface

##  Getting Started

1. Download or clone the project.
2. Open the project folder.
3. Launch `index.html` in any modern web browser.
4. Upload one or more images.
5. Adjust the compression settings.
6. Click **Compress**.
7. Preview and download the optimized images.
